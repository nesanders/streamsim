What this test evaluates

The hybrid strategy picks the best available backend automatically. If WebGPU is available (most modern laptops and desktops running Chrome or Edge), a 0.6B model runs entirely in the browser — no API key, no server. If WebGPU is not available (older devices, Firefox, standard Chromebooks), the assistant falls back to the Groq API, which requires a free API key entered by the teacher.

This page runs the same three tests — Q&A, function calling, scenario generation — on whichever backend your device supports, so you can compare quality and speed directly.
